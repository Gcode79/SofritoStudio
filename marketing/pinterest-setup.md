# Pinterest Setup + First 10 Pins — Sofrito Studio

## 1. Create the account (you, ~10 min)
1. Go to **pinterest.com/business/create** → sign up as **Business** (free)
2. Business name: **Sofrito Studio** · Profile URL: `pinterest.com/sofritostudio`
3. Website: `https://sofritostudio.com`
4. Category: **Food & Drink**
5. **Claim the site:** Settings → Claim → Add website → add the HTML meta tag Cloudflare gives you to `deploy/index.html` (or via DNS TXT) → I'll deploy it. This unlocks analytics + "Website" attribution.

## 2. Board structure (create these)
- **Puerto Rican Recipes** (main)
- **Boricua Favorites** (mofongo, pernil, alcapurrias…)
- **Sides & Rice** (arroz con gandules, habichuelas…)
- **Desserts & Drinks** (coquito, tembleque…)
- **Nochebuena / Navidad** (holiday — the spike board)
- **Thanksgiving Boricua**
- **Air Fryer & Quick Meals**
- **Sofrito Studio Products** (cookbooks/guides)

Name boards with keywords ("Puerto Rican Recipes", "Boricua Christmas Recipes") — Pinterest search matches board titles.

## 3. Pin recipe (best practice)
- Image: **1000×1500** (2:3) vertical, bright food photo, **bold text overlay** (2–5 words)
- Title: keyword-first, e.g. "Authentic Puerto Rican Mofongo Recipe"
- Description: 1–2 sentences + **2–3 keyword hashtags** (#mofongo #puertoricanrecipes #boricuafood)
- Destination: the blog post URL (→ its product CTA)
