# Analytics Contract

Keep event names stable. Add or change events only with a documented reason.

## Core events

- `page_view`
- `landing_view`
- `cta_click`
- `product_view`
- `checkout_start`
- `purchase`
- `email_signup`
- `lead_magnet_download`
- `content_engagement`
- `experiment_exposure`

## Event design

Every event should answer:
- what happened?
- where did it happen?
- what product/content was involved?
- which experiment variant was shown, if applicable?

Do not include unnecessary PII.
