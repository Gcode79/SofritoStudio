# Growth Experiments

Each experiment should contain:

- ID
- hypothesis
- audience
- control
- variant
- primary metric
- secondary metrics
- start date
- end date
- result
- decision
- rollback notes

Example:

## EXP-001 — Cookbook Hero CTA

Hypothesis:
A specific product-oriented CTA will outperform a generic learn-more CTA.

Primary metric:
checkout_start / landing_view

Secondary:
purchase / landing_view
CTA click rate

Decision:
Ship winner only after sufficient evidence.
